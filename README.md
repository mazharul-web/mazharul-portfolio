# Mazharul Islam — Personal Portfolio Website

A responsive, dark professional portfolio website for an Electrician / Electrical Technician job seeker targeting European opportunities. Built with plain HTML, CSS and JavaScript. No framework or build process required.

## Files
- `index.html` — page content
- `styles.css` — responsive layout and design
- `script.js` — mobile navigation and current footer year
- `assets/profile-photo.jpg` — replace this with your own professional photo

## Run locally
1. Extract the ZIP file.
2. Open `index.html` in a modern browser.
3. Replace placeholder contact details and project descriptions before sharing.

## Add your photo
- Create/use the `assets` folder.
- Put your portrait in it and name it `profile-photo.jpg`.
- Recommended: a clear, professional portrait in JPG format, cropped vertically.
- If your photo uses another format, either convert it to JPG or update the image path in `index.html`.

## Important personalization checklist
- Replace `YOUR.EMAIL@example.com` in the visible email, `mailto:` links and contact button.
- Replace the LinkedIn link with your real profile URL.
- Replace project placeholders with real projects and your own photos.
- Add only verified work dates, duties, education, certificates, language levels and work authorization details.
- Remove any section that does not apply to your actual experience.
- Check the page on a phone before sharing.

## Free hosting with GitHub Pages
1. Create/sign in to a GitHub account at https://github.com/
2. Create a new public repository, for example `mazharul-portfolio`.
3. Upload `index.html`, `styles.css`, `script.js`, and the `assets` folder to the repository root.
4. Open repository **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select branch `main` and folder `/ (root)`, then save.
7. Wait for GitHub Pages to publish the site. The public URL appears in Settings → Pages and typically looks like `https://YOUR-USERNAME.github.io/mazharul-portfolio/`.

Hosting provider screens and options can change. If using Netlify instead, sign up at https://www.netlify.com/ and deploy the extracted site folder using its current manual deploy flow.

## ATS / recruiter note
A portfolio website does not replace a CV and is not itself an ATS CV. This site uses readable headings and plain text. Keep your separate CV simple, text-based, and tailored to each vacancy. No experience, qualification or certificate has been invented in this template.
